# 12件装备

all.json含全部12件装备。若你还没有导入之前的驱散模块标签更新，可用with-turning-update.json（12件装备＋一项驱散兼容更新）；预览时核对turn_undead已有自定义字段。

- 钉头锤：中型、20／×2，装备后在玩家操作里切换“目标是邪恶异界敌人”；本武器增强从1变3，再加2d6。其他武器不受影响。
- 全身甲：中型、中甲，20速减5、30速减10；检定减值-3，游泳按双倍减值-6。
- 重盾：护甲2＋自身增强1＝盾牌贡献3，与盔甲的9点贡献分别叠加；不加接触防御。护命25%仅备注，现场掷骰。
- 戒指天生防御2只加普通和措手不及防御；魅力斗篷为短效增强+2。
- 珍珠与原来的一环珍珠相同，只记录1次恢复，法术位手动处理。
- 延时权杖记录3次，次数大于0才显示备注；持续时间手动处理，不自动增加环位。
- 夜之杖对已有驱散池初始和上限+4，与额外驱散专长可合计+8；已有当前剩余次数由DM按实际情况手动加4，旧资源不被自动回满。移除夜之杖后上限回退，当前数值若超限请DM手动处理。
- 次级回春术法杖暂放特殊位置。50次充能，使用按钮每次-1；治疗只保留描述，不自动改血量。rechargeable:false确保不被自动恢复；每日恢复按钮尚未新增，未来也会遵守此标志。

先刷新网页，再批量导入并把装备分配给角色；选入相应装备槽后生效。多个特殊装备使用现有的可新增特殊槽。
