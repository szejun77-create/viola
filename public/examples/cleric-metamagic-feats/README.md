# 八项专长与超魔

推荐导入 with-turning-update.json：八项新专长，加一项兼容的驱散不死生物定义更新。批量预览中允许更新turn_undead，保留你自己另加的字段。all.json只含八项新专长；若用它，另导入turn_undead-update.json，否则旧驱散模块缺少turn_undead标签，无法收到额外驱散的加成。

- 额外驱散：已有驱散资源初始值／上限+4，不凭空创建资源。已经保存的当前剩余次数不自动变化，请DM按实际情况手动+4；新初始化的资源会包含加成。
- 战斗施法：在专注技能的“防御式施法、被压制或擒抱时”情境列显示+4，不加进平时检定。
- 持盾施法：可开启的纯战斗备忘，是否持轻盾／重盾／塔盾由玩家判断。
- 法术瞬发+4环；法术扩展+1环；法术孪生+4环；法术增远+1环。升环按本团指定数值，不擅自改成其他版本规则。
- 神圣超魔：法术瞬发仅备注，不自动扣驱散或抵消瞬发按钮的升环，由你手动处理。

孪生只消耗一次本次施法所需法术位与施放操作资源，把本次生成的持续记录复制成两份，可分别到期、删除、接受。自身持续增益仍由同一个模块提供，友军的一对孪生增益数值也不重复相加；一份结束后另一份仍有效。两份备注保留给你分别判定豁免和解除。直接伤害、即时法术的第二次结算仍由人处理，不自动掷骰或把伤害数字乘二。

延时可以与孪生同时开启；两份记录都取得延时后的持续时间。冻寒／灼热金属仍分别保留开始／主要阶段，孪生后是两组记录，不把两个阶段混为同一个法术。专注法术两份记录共用该角色的“停止专注”操作，不产生第二个可独立维持的专注动作。

刷新本地网站，导入定义并分配到角色后，超魔按钮会自动出现在施法区。
